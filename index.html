⚙️ First-Time Setup
This dashboard uses Firebase (Google's free cloud) so your trades are safely stored and the Admin can view them from any device.
  • 1Go to console.firebase.google.com → Create project → name it "ORB-Dashboard"
  • 2In your project → Authentication → Sign-in method → Enable Email/Password
  • 3Authentication → Users → Add user twice: one for the Trader, one for the Admin
  • 4Firestore Database → Create database → Start in Production mode → Choose nearest region
  • 5Firestore → Rules → Paste the rules from the "Firestore Rules" tab → Publish
  • 6Firestore → Data → Add collection admins → Add document with Document ID = Admin's UID (find UID in Authentication → Users)
  • 7Project Settings (⚙️ icon) → Your apps → Add app → Web → Copy the firebaseConfig object
  • 8Come back here → click "Enter Firebase Config" tab → paste and save
Paste your Firebase config object here. It looks like: { apiKey: "...", authDomain: "...", ... }

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Check if user is admin function isAdmin() { return exists(/databases/$(database)/documents/admins/$(request.auth.uid)); } // Trades: traders write own, admin reads all match /trades/{tradeId} { allow create: if request.auth != null && request.resource.data.uid == request.auth.uid; allow read, delete: if request.auth != null && (resource.data.uid == request.auth.uid || isAdmin()); } // Capital: any auth user can read/write match /capital/{docId} { allow read, write: if request.auth != null; } // Admins list: readable by all auth users match /admins/{uid} { allow read: if request.auth != null; allow write: if false; } // Open positions: own user reads/writes, admin reads all match /positions/{posId} { allow create: if request.auth != null && request.resource.data.uid == request.auth.uid; allow read, update, delete: if request.auth != null && (resource.data.uid == request.auth.uid || isAdmin()); } } }
